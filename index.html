Objetivo del proyecto:
Recrear un caso realista de análisis completo del ciclo de datos: desde la adquisición y limpieza hasta la generación de insights y recomendaciones accionables para la toma de decisiones.

Preguntas de negocio que abordo:
• ¿Qué patrones explican el comportamiento principal de los usuarios o entidades analizadas?
• ¿Qué segmentos o grupos se comportan de forma similar?
• ¿Qué variables resultan más relevantes para explicar el resultado de interés?
• ¿Qué acciones prácticas se podrían derivar de los hallazgos?

Metodología:
• Limpieza y preparación de datos (detección de valores atípicos, imputación, codificación).
• Análisis exploratorio de datos (EDA) para entender distribuciones, relaciones y tendencias.
• Construcción y evaluación de modelos predictivos básicos para responder preguntas concretas.
• Visualización de resultados y redacción de conclusiones entendibles para perfiles no técnicos.

Resultados e impacto potencial:
El proyecto identifica segmentos con comportamientos diferenciados y variables clave que influyen en el resultado objetivo. A partir de ello planteo recomendaciones (por ejemplo, qué grupos priorizar, qué métricas monitorear y qué pruebas adicionales podrían hacerse), mostrando cómo este tipo de análisis puede apoyar decisiones en un contexto real.

Clasificación de reseñas de Amazon

Desarrollo un clasificador de sentimiento para reseñas de productos de Amazon utilizando técnicas de procesamiento de lenguaje natural (NLP). El objetivo es automatizar la identificación de opiniones positivas y negativas para apoyar la monitorización de la experiencia del cliente y detectar problemas recurrentes en productos y servicio.

Trabajo el pipeline completo: limpieza de texto, tokenización, representación mediante TF-IDF, entrenamiento y evaluación de modelos de clasificación, además de visualizaciones que ayudan a entender qué términos se asocian con cada tipo de reseña.
